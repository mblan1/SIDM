Snw Internet Download Manager

Fast multi-segment downloads, browser capture, native HLS & DASH video grabbing, queue + schedule + bandwidth governor — for modern Windows.

⬇ Download for Windows View source

Windows 10 / 11 · 64-bit · ~70 MB · Free · Auto-updates via Velopack

What you get

Real multi-segment

1–16 parallel range requests per download, sparse-file writes, single-stream fallback when servers fib about Accept-Ranges. Resumes across app restarts.

Browser capture

Chrome MV3 and Firefox MV3 extensions intercept downloads with full cookies / referer / User-Agent replay, so SIDM gets the exact bytes the browser would have.

HLS & DASH from scratch

Pure-C# m3u8 parser with AES-128 decrypt and pure-C# MPD parser with video + audio mux via ffmpeg. yt-dlp routing for YouTube & friends.

Queue & bandwidth

Cap concurrent downloads, set a global token-bucket speed limit, define time-window schedule rules with their own per-window overrides. Drop 50 URLs and walk away.

One-click capture popup

SIDM extension auto-sniffs HLS / DASH manifests on every page. The toolbar badge shows the count; the popup lets you grab any of them with one click.

Auto-updates

Velopack delta updates from a single configurable feed URL. Toggleable in Settings. Signed installer, opt-in crash reports with URL / cookie / filename scrubbing.
